# Importing activities

Kondis supports importing activities in `.fit`, `.tcx`, or `.gpx` format. Click the `Upload Activity` button.

Kondis also supports Strava takeout files. Click the `Strava takeout` button. All supported features will be imported. These inclulde

- All Strava activity types, from running to wakeboarding
- Workout maps and statistics
- Photos
- Profile pictures

The following data is known not to be imported:

- Activity crops
- Shoes and other gear
- Comments by other users
- Routes
- Segments

Note that Strava takeout files must be in English language. If you have the wrong language setting in Strava while creating the takeout file, it will not be understood by Kondis.
