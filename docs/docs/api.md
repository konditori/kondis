# API reference

The [Kondis API documentation](https://api.kondis.org/introduction) is generated directly from the checked-in [`open-api/kondis-openapi-specs.json`](https://github.com/konditori/kondis/blob/main/open-api/kondis-openapi-specs.json). It is the exhaustive reference for every operation, grouped by tag, including authentication, parameters, request bodies, response types, errors, and reusable schemas.

Use the interactive examples on each operation page to inspect the request shape. Upload and takeout processing is asynchronous; use the returned status or activity events instead of assuming parsing finished when the HTTP request returns.
