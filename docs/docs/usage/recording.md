# Recording a workout

In order to record a workout, install the mobile app on your Android phone. iOS support is planned for the future.

After installing the development Android app, login to your Kondis server and start tracking your progress.

## Live workouts

When starting a workout, your followers can track you on a Live workout. This is currently only possible within the app, but a planned feature is sending a link over text to a friend who can keep track of you without needing the app itself.
