# Installation via docker compose

Docker compose is the recommended install method. 

## Step 1: Clone the files

At the moment, the only way to download the app is to clone it with git.

```bash
git clone https://github.com/konditori/kondis.git
cd kondis
```

## Step 2: Populate the env file

Next, setup the environment file. You can begin by coping the sample env file

```bash
cp docker/env.example .env
```

Then edit the file to suit your needs. Here are the most important variables:

<CodeBlock language="bash" title="Default environmental variable content">
  {ExampleEnv}
</CodeBlock>

## Step 3: Start the containers

```bash
mise dev-update
```

If successful, continue to post-installation steps.
