# Contributing

Keep changes focused, add tests for behavior changes, and update the relevant documentation. Do not commit secrets, generated local databases, or personal activity files.

Generated OpenAPI, translation, and license artifacts are committed and must be regenerated when their sources change. Kondis is licensed under AGPL-3.0-or-later; third-party notices are in `THIRD-PARTY-LICENSES.md`.
