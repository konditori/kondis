# Importing activities

Use **Add activity → Upload activity** for an individual `.fit`, `.tcx`, or `.gpx` file. For Strava, request a data export and upload its `.zip` from **Add activity → Import Strava takeout**.

Importing and parsing are asynchronous. Strava takeouts do not preserve crop boundaries, so an original untrimmed file may disagree with edited CSV metrics. Cropped workouts must be re-cropped manually.
